Villager News: NeoForged
Unofficial NeoForge 1.21.1 Port

This project is an unofficial Java Edition / NeoForge port of the Villager News Bedrock add-on by Oreville Studios.

This port contains content originating from the original Bedrock add-on, including assets such as models, textures, sounds, animations, and other content.

I did not create the original Villager News content.

My contribution is the work required to make the add-on function as a Java Edition NeoForge mod, including the Java/NeoForge implementation, compatibility work, bug fixes, and porting logic.

This project is not affiliated with, endorsed by, or officially supported by Oreville Studios.

Original project:
Villager News by Oreville Studios

Requirements:
- Minecraft 1.21.1
- NeoForge
- Java Edition

Installation:
1. Install NeoForge for Minecraft 1.21.1.
2. Place the .jar file into your Minecraft mods folder.
3. Launch the game using the NeoForge profile.
